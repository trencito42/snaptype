# Store listing images

Six 1280x800 PNGs per store (`chrome/`, `firefox/`), the size both the Chrome Web Store and Mozilla Add-ons accept.

- Every UI element is a **real capture** of the SnapType extension / dashboard running in Chrome 157 against a throw-away backend (`scripts/brand/capture-store-shots.mjs`). Headline text and backgrounds are added by `scripts/brand/compose-store-shots.mjs` (Clarity City, brand colours).
- The page behind the extension is a **fictional demo helpdesk** (`scripts/brand/demo-page.html`); names and data are made up. It is not a screenshot of any third-party product.
- `firefox/` currently holds the same images as `chrome/`: the extension UI is identical (same code). Firefox-native captures can be regenerated by the same scripts once they are pointed at a Firefox session; this has not been done, so do not describe them as Firefox captures in the listing if a store asks.
- The native browser context menu cannot be captured by browser automation, so no image shows it.

Regenerate:

```bash
node scripts/brand/capture-store-shots.mjs      # real captures into .e2e-tmp/raw
node scripts/brand/compose-store-shots.mjs      # slides into docs/release/store/{chrome,firefox}
```
